# 🏆 finals mode

A good-luck page for finals: a battery boot-up + rocket launch, then 8 mini activities that each unlock a badge
(luck charger, stress bubbles, fortune cookie, magic 8-ball, compliment slot machine, survival kit, focus timer,
and a downloadable certificate). Unlock all 8 for legendary status 👑

Everything lives in `index.html`, so there's no build step. Progress is saved in the visitor's browser.

## Personalise the link (optional)

```
https://<your-username>.github.io/finals-success/?to=Sarah&from=Gaby
```

`to` shows up on the hero and the certificate, and `from` signs the certificate. You can also set `CONFIG` at the top of the `<script>`.
